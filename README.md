# G&M Finance

Family expense tracker for Gal and Menash. A single-page web app on GitHub Pages, with data in Firebase (Firestore + Google sign-in).

- `index.html` – the whole app
- `firestore.rules` – security rules (paste into Firebase console → Firestore → Rules)
- `manifest.webmanifest`, `icons/` – home-screen icon and full-screen mode

No financial data is stored in this repository.
